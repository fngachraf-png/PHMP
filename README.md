# 💊 PharmaCare Pro - نظام إدارة الصيدليات الإحترافي

نظام SaaS متعدد المستأجرين لإدارة الصيدليات بشكل إحترافي، يعمل كتطبيق ويب تقدمي (PWA) مع دعم كامل للغة العربية والإنجليزية.

## ✨ الميزات الرئيسية

- 🌐 **ثنائي اللغة**: دعم كامل للعربية (RTL) والإنجليزية (LTR)
- 📱 **PWA**: يعمل على أي جهاز، قابل للتثبيت، يعمل دون اتصال
- 🏢 **SaaS Multi-tenant**: يدعم عدة صيدليات بمستخدمين مختلفين
- 🔐 **نظام صلاحيات**: مدير، صيدلي، محاسب
- 🛒 **نقطة بيع (POS)**: مع بحث بالباركود، عدة طرق دفع، فواتير
- 📦 **إدارة المخزون**: تتبع الدفعات، تواريخ الصلاحية، تنبيهات ذكية
- 📋 **الوصفات الطبية**: إدارة كاملة مع سجل المرضى
- 👥 **العملاء**: قاعدة بيانات + نقاط ولاء
- 🚚 **الموردين والمشتريات**: أوامر الشراء، الفواتير
- 📊 **التقارير**: تحليلات شاملة مع رسوم بيانية
- 💾 **حفظ محلي**: البيانات تُحفظ في localStorage

## 🚀 طريقة التشغيل

### المتطلبات الأساسية
- Node.js 16+ و npm

### خطوات التشغيل

```bash
# 1. تثبيت المكتبات
npm install

# 2. تشغيل بيئة التطوير
npm run dev

# 3. افتح المتصفح على
# http://localhost:5173
```

### بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

## 🎯 الصفحات المتاحة

1. **لوحة التحكم** (`/dashboard`) - نظرة عامة + KPIs
2. **نقطة البيع** (`/pos`) - بيع سريع مع بحث بالباركود
3. **المخزون** (`/inventory`) - إضافة/تعديل المنتجات
4. **الوصفات الطبية** (`/prescriptions`) - إدارة الروشتات
5. **العملاء** (`/customers`) - قاعدة بيانات العملاء
6. **الموردين** (`/suppliers`) - إدارة الموردين
7. **المشتريات** (`/purchases`) - أوامر الشراء
8. **التقارير** (`/reports`) - تقارير المبيعات والمخزون والأرباح
9. **الإعدادات** (`/settings`) - إعدادات النظام

## 🏗️ البنية التقنية

- **React 18** + **Vite** (أداء سريع)
- **TailwindCSS** (تصميم عصري)
- **React Router** (التنقل)
- **Recharts** (الرسوم البيانية)
- **Lucide React** (الأيقونات)
- **Context API** (إدارة الحالة)
- **localStorage** (تخزين البيانات)

## 🎨 الهوية البصرية

- **اللون الرئيسي**: أخضر طبي (#10B981)
- **الخط**: Cairo للعربية + Inter للإنجليزية
- **الثيم**: فاتح (قابل للتوسيع للداكن)

## 📱 خصائص PWA

- ✅ قابل للتثبيت على الهاتف/سطح المكتب
- ✅ يعمل دون اتصال (Offline)
- ✅ شاشة بدء مخصصة
- ✅ Service Worker للتخزين المؤقت
